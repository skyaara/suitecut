# suitecut 0.1.0 alpha: release record

The first native-only release, for macOS arm64. This page records what was
built, from which sources, and what was checked, as `RELEASING.md` asks. The
archives were built and checked on 2026-11-23 on macOS 27.0.1 (Apple M4,
16 GB). Nothing here is published by this record itself.

The runtime archive is held: it bundles Homebrew's FFmpeg 9.0.1, a GPLv3 build
with x264 and x265, which needs its complete corresponding source to be
redistributed, and its engine is the third-party codec build of CEF. The SDK
archives and the embed kit contain neither.

All binaries are signed with the Developer ID certificate of team `WTD7AF5L23`
and timestamped. None is notarized yet.

## Checks

Gates are numbered as in `RELEASING.md`.

| Gate | Result |
| --- | --- |
| 1. Clean-checkout build | Engine and client build from a fresh clone; the app reports version 0.1.0. |
| 2. Client tests | Release: 26 of 26 (static and shared). ASan and UBSan: 26 of 26. |
| 2. Fuzz campaigns | JSON and packets, seed `5355495445435554`: 5,000,000 iterations in Release, 1,000,000 under ASan. Agent observation, seed `4147454e545549`: 500,000 in Release, 50,000 under ASan. |
| 3. Control CLI fuzz | `fuzz-native-control.py`, seed `53455353494f4e`: 10,000 iterations; worker memory, descriptors and threads flat. |
| 4. Engine checks | 192 pass, with `native-http-lookup-transport` skipped. |
| 5. CEF regression suite | 5 of 5 C++ workflows, seed 23; 41 of 41 harness unit tests. |
| 6. Installed SDKs | C and C++ consumers build and pass against relocated static and shared prefixes with Homebrew hidden from CMake. The shared SDK's consumers need no OpenSSL. |
| 7. Runtime archive | Verified from a relocated extraction: 330 manifest hashes, signatures, the CLI without Node or Homebrew on `PATH`, and the live C++ browser checks. |
| 7. Recording | `.mp4`: 12 of 12 cases, to 3840×2160 at 120 FPS. `.webm`: 10 of 12; see known issues. |
| 8. Embed kit | `verify-embed-kit-macos.py`: 56 of 56. `verify-embed-sample-macos.py`: pass. Signatures verify after extracting the archive. |

Limits of these checks:

- The sanitizer and fuzz runs used the client built against Homebrew's
  OpenSSL 4, before the client was relinked against static OpenSSL 3.5.9. The
  client's own source is the same; the Release tests, the CEF suite and gates
  6 and 7 were repeated on the relinked builds.
- macOS ASan has no leak detector, so no leak check ran. Prebuilt CEF is not
  sanitizer instrumented.
- Nothing was run on macOS 14 or 15 themselves. The minimums are what every
  packaged Mach-O file declares, enforced by the packager's `--require-macos`.
- Linux x64 was not built or tested. Windows packaging does not exist.

## Known issues

- A `.webm` recording with audio can open with about 140 ms of silence; `.mp4`
  does not.
- Software VP9 (`.webm`) does not hold 120 distinct FPS above 1920×1080.
- Codec playback acceptance and folder upload have no native checks yet.
- `get url`, `get title` and `read` read again across a navigation, but
  `evaluate` still fails if its document is replaced while it runs.
