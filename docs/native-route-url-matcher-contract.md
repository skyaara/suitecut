# Route URL matcher ownership contract

The native registry owns the immutable Page-before-Context reverse-registration snapshot. Peek does not consume times. Decide accepts only its exact snapshot index, registration and native generation, advances one candidate, then consumes only an actual true result whose registration remains available. Shared Context policies keep their one actual global counter. Native glob/HAR Next never treats a host matcher placeholder as a match. When a queued candidate was genuinely removed/exhausted, the native registry skips its unavailable original generation and returns an explicit skipped receipt; absence of SDK host state alone never authorizes that skip. Allows never grants a host policy CORS authority.

NativeRouteMatcherSelections owns at most 128 global logical selections and 4 MiB of reserved plan, URL, retained-adapter-payload and selection string metadata. Its original fixed deadline is checked on admission, result and tick. Every host candidate receives a genuine NativeRouteCallbackLeases token. Boolean results require its actual settled receipt; invalid results may abort logically while the actually running callback remains retained until its real finish or physical process boundary. Late results, stale tokens, removal, ID reuse, owner closure and reentrant completion cannot redirect another selection.

The SDK snapshots RegExp source/flags. Every invocation uses a fresh clone starting lastIndex 0 (including g/y), never the caller's mutable lastIndex or overridden test. Predicate input is a real URL parsed from the native observed URL; the declared contract is synchronous boolean. Promise/thenable returns are invalid. The bridge sends that invalid-result notification to the real native owner before waiting on the actually started continuation; logical scope close or failed abort cannot release its physical start/finish lease. A genuine Promise is branded by node:util/types and observed with a module-captured intrinsic then, bypassing author-owned then properties. If an author constructor/species hook prevents attaching that observer, the host continuation remains conservatively pending; no finish ACK or zero physical count is invented. This pathological callback can retain one bounded host slot until the SDK process exits. Arbitrary thenables expose only their actual invoked then protocol; unrelated hidden background work is not inferred. An eventual observable continuation rejection stays separately visible, and actual start/finish/decision command rejections are tagged at their genuine command boundary and retain precedence over ignoreErrors. A genuine boolean is sent only after real native finish ACK.

Registration bridge quota is 1024 active host matcher policies and 4 MiB source+flags; actual pending callbacks retain the existing 128 physical host cap. Dispose ends active registration ownership, while already captured callbacks retain their actual function/regex snapshot through physical settlement.

The adapter accepts Page/Context RegExp and synchronous URL predicates, routes genuine native matcher control packets without fabricating Request/Route events, and resumes the original native snapshot after the actual callback receipt. Fallback matches the initial observed URL even if earlier handlers override the outgoing URL. Removal wait/ignoreErrors capture the same actual matcher callback receipts as ordinary route callbacks. Context callback routing retains actual Source/broker ownership, including targets without a Page.

Automatic CORS authorization requires an actually observed exact parent request and a genuine admitted matching parent policy. A host placeholder never authorizes it. If the parent matcher has not run, the automatic pause remains bounded under its original deadline; an actual invalid parent result aborts it. A parent Fetch pause which cannot become available before preflight completion remains an explicit unsupported ordering; there is no fabricated parent callback or speculative true result.

Fallback commands retain their original native operation deadline and exact admission generation. The native context bridge issues its own monotonic admission nonce before forwarding; canceled logical observers do not release the actual Source/broker sender callback, and a late receipt cannot complete an operation reusing the integer ID. A genuine Fetch ACK after the original fallback deadline retires physical transport ownership but cannot publish success, even if Tick has not yet run. Initial native pause selection remains separately bounded at 30 seconds. Native selector snapshots are charged independently of the existing physical callback lease book.

Controlled native/SDK proofs pass for the adapter. Matching compiled public browser proof is still pending; the official verifier records real wire absence, actual author callbacks and actual helper closure. The Source patch is a separate three-hunk Root-owned handoff, not a copied browser.cc.
