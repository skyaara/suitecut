# Retained native process host adapter prerequisites

This unit provides real dedicated-host fd4 inheritance, native selected-callback registration policy, and private SDK setup/launch marshalling. It does not enable CEF reuse. The native runner coordinator binding is a separate pending patch: existing native_runner invokes the default host constructor and only three ordinary host arguments, so the SDK emits no SOURCE_CAP/new packets. The private protocol is enabled only by the exact native `--suitecut-source-endpoint=4` marker plus an inherited socket. Old host streams remain unchanged when this marker is absent.

Native setup selection uses FixtureOptionCatalog::Origin::Callback, actual worker scope, and a nonzero genuine associated test ID. Declared/configured constants and hook-only acquisitions with test ID0 have no Source bridge. Version/declaration IDs come from the native catalog; flat authored keys are never parsed as nativeFixture IDs. Only a setup that remains open before first use/READY can reserve. Admission denial is distinct from valid fresh-only fallback (one helper per host, bounded capacity). The thin SDK passes native IDs, closes setup admission before use, waits real startup ACK, and keeps accepted-but-unobserved/cancel-unACKed reservations in its queue. Immediately before spawn it rechecks the same callback is open after profile awaits. Native startup and the original actual browser-ready receipt are separate conditions.

The original native host keeps its direct waitpid; the one existing ProjectDescendants remains the sole adopted-child waitpid owner. A held source child does not become physically zero on pidfd readiness, shutdown label, cancellation admission, or host exit. Source DomainArrived captures the exact real domain owner before its batch clears. Final retirement additionally verifies actual native host Exited(), that exact batch Pending()==false, registration channel drain, and the retained source pidfd exit. Source outstanding must gate group/lock/publication retirement, but cannot block Descendants.Arrive itself: the real adopted source must be allowed to reach that sole reaper.

Ordinary Tick propagates malformed transport receipts. A failed native actor can instead use bounded Drain while retaining its original exception: Drain closes startup authority, emits no startup response, and retains the first additional exception_ptr while continuing channel/pidfd observation on subsequent ticks. RetireDrained still requires the original physical receipts. Its caller must report DrainFailure as infrastructure failure (or rethrow its original exception after verified cleanup); a transport error must never become a successful report. The coordinator binding must keep this fallible work inside its existing actor failure/drain boundary, preserving the fixed emergency grace. The drain component exercises malformed initial startup and malformed post-startup traffic, each with two real credentialed packets and a genuinely blocked child, then verifies exact original host waitpid, sole-domain SIGKILL/waitpid, channel EOF and physical retirement while both errors remain retained.

The optional setup-sidecar history is bounded64. When full, a further otherwise valid callback receives no bridge and follows existing fresh behavior; existing ticket continuation contexts are retained. A repeated native callback token remains rejected. Exhaustion of registration instrumentation never rejects the ordinary fixture admission.

Component controls exercise native host/child processes and the real existing shared subreaper. SDK unit controls exercise marshalling and selected-origin rejection. These controls do not claim a CEF Engine shutdown, a Node SDK-host registration integration, or a process-wide accepted-work idle barrier. The coordinator binding and actual matching CEF endpoint proof remain pending. Every unknown/CEF child still disqualifies worker reuse.
