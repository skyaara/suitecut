# Retained native process receiver prerequisites

This module is staged and does not enable CEF worker reuse. It owns one credentialed registration socket and persistent native pidfd for one native browser helper per actual SDK host. The caller binds the original native-owned host PID/start identity, then reserves a ticket with the actual selected worker-fixture catalog/declaration, setup token, test and generation. A second helper uses the existing fresh-worker path; it cannot share another ticket.

Startup requires the kernel sender PID/UID/GID, exact native host parent/start identity and expected executable inode/device. The pidfd remains owned across the child lifetime. Its readability observes the same child exit; it does not reap the child or replace either the SDK parent's child waitpid or the runner's sole existing adopted-descendant subreaper. A shutdown-boundary packet is only an authenticated label. No idle or CloseReceipt is issued from it. Final policy retirement additionally requires the actual host waitpid, drained channel, and existing shared descendant-batch retirement. Socket/handle destruction alone does not retire the policy ticket.

The private SDK setup-context module is likewise a prerequisite: it forwards native-selected callback identity without interpreting flat authored fixture keys as layered declaration IDs, closes admission before the first use/READY, preserves native fresh-only/rejected responses and startup queue ownership, and passes through actual callback returns/errors. It is not yet connected to host SETUP or browser launch. Native literal/configured-constant setups must never invoke it. Neither the transport nor this module claims protection from malicious SDK mutation/imports.

Activation remains blocked on a process-wide native Engine accepted-work ledger covering pages, contexts, original Inspector callbacks, deferred sends, broker/HTTP/files/media and writer retirement. The accepted-work backend and central browser hook remain absent. Unknown children and all current CEF children still disqualify reuse.
