# Corrected ownership observer for the actual host PID

Output-directory admission validates the native-owned worker index and OS PID before accepting `OUTPUT_CONTEXT`, then returns the exact native owner IDs in its readiness ACK. The shipped public runner API selects its own host module; it does not advertise an arbitrary process-spawning SDK-host wrapper option.

Some authored fault checkers previously inserted a separate Node relay process as the native worker and executed the SDK host in its child. With output-directory owner validation, the SDK child's actual `process.pid` differs from the native-owned relay PID. The preserved local-file ownership failure contains a genuine `HOST_ERROR` from `NativeOutputCallbacks.packet`: `Stale native output directory admission owner`. The native directory writer had really completed, but no host readiness ACK or user callback was admitted. This is recorded as an incompatible fault-observer topology, not as a passing old proxy.

`scripts/native-runner-observed-host.mjs` uses Node's public `syncBuiltinESMExports` mechanism to select a real Socket subclass for the test host's actual fd3 socket. It imports the actual authored SDK host in that same process. Incoming and outgoing genuine control lines can be journaled, withheld, and later forwarded, while all original protocol fields, native outcomes, callback/IO receipts, stdout/stderr and OS process exits remain real. Non-fd3 sockets use the original Node operations. The helper creates no callback result or native ACK and performs no user-test scheduling.

The ten authored ownership observers share this helper. Their existing request/ACK/ordered-tail/physical-receipt delays and assertions are retained. The declared-skip PID witness now records the actual same-process SDK/native host PID, rather than a now-absent extra observer child; its actual process-exit assertions remain unchanged. The separate user-descendant checker still launches genuine user children and is unchanged. The corrected observer scopes do not claim the old additional relay-child coverage.

Only the previously failing local-step attachment ownership scope and its unfinished ACK/receipt/deadline tail were rerun privately with this observer. The other eight adaptations were syntax checked for the next combined CTest run. The original incompatible proxy report, the earlier receipt-path wrapper error, and all completed positive scopes are retained in separate evidence directories. Production PID checks were not relaxed.
