# Native locator predicates

`Locator.waitForFunction(predicate, argument?, {timeout, signal}?)` returns void
when the predicate's actual return value becomes truthy. The pinned public
contract and ten unchanged cases are from606ecd8b; this API first appeared in1.62.

C++ owns every selection and retry. QueryInspect selects in the actual utility
realm, enforcing native strict diagnostics. The selected backend DOM node is
adopted into that frame's actual main world before invoking the user predicate.
Custom selector engines keep their declared execution worlds through the existing
query planner. A Promise is awaited once; only an actual missing selection or
false boolean result schedules another native retry. User exceptions/rejections
are not classified by their text and never cause a replay.

Typed arguments retain genuine native handle IDs. Same-frame wrappers retain
their creation context; only actual same-origin DOM nodes may be adopted across
frames in the same target session. Each argument's full ReferenceDocument and
handle creation unique context/renderer epoch is checked. No arbitrary author
object is reinterpreted as a private UTF16 tag. Function-source scalar transport
explicitly rejects isolated units; typed argument values and selected native
exception strings remain lossless.

The active ordinary operation quota bounds jobs at64. Per-job arguments are
bounded at1024 and distinct pinned documents at64. The original generation and
deadline plus every frame/session/loader/numeric+unique context/native epoch pin
are checked before dispatch, actual receipt and final successful Complete,
including any native causal publication hold. No retry extends the deadline.
Logical work remains strongly owned through that last publication boundary.

Before the first physical selection, temporary groups transfer out of the generic
evaluation tracker into SelectorWaits. Logical abort/timeout removes logical work,
while actual Inspector calls and all temporary groups remain physically owned
until their ACKs or real channel destruction. Existing bounded physical watchdogs
post native teardown; no synthetic settlement frees admission.

Controlled tests include the actual product include and production SelectorWaits:
17 groups cover selection/adoption, genuine re-selection, argument wrappers,
false/native retry, errors without replay, UTF16 exception provenance, old owner
IDs, same-numeric context replacement, expiry before Tick, held selection/async
call abort and deferred successful publication. SDK5 tests cover the packet,
argument identity, value/tag separation, AbortError cause and option validation.
The official real browser12 checker and unchanged public10 require a new matching
compiled epoch; controlled success is not a public runtime parity claim.
