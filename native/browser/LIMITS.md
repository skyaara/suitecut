# Native limits backlog

Every fixed-size table and byte limit in `native/browser` that Chrome or Playwright
does not have, from the November 2026 audit. A limit only exists to bound memory:
when one is reached the page and browser stay open, the oldest record is
forgotten or the payload is clipped, and `diagnostics` reports it under
`degraded`. A row here means a page Chrome loads fine could still fail an
operation, or lose data, through suitecut bookkeeping.

`changed` means the audited value no longer appears in that file and should be
re-checked before it is crossed off; `open` means it has not been touched yet.
Regression cases for limits already raised are in `tests/cef/scenarios/resilience.mjs`;
`pnpm soak:real-sites` replays the real sites that found them.

441 rows: 430 open, 11 changed since the audit.
