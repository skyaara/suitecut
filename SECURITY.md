# Security policy

## Supported versions

Security fixes target the latest published minor release in the current major version. Older minor
releases may need to upgrade to receive a fix.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting form](https://github.com/skyaara/suitecut/security/advisories/new).

Include the affected version or commit, the operating system, a minimal reproduction, the expected
impact, and any suggested mitigation. Remove tokens, private URLs, recordings, and customer data
from the report. The maintainers will coordinate a fix and public disclosure with the reporter.
