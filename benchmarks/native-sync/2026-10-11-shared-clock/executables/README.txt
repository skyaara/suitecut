Linux x64 executables retained for provenance. These depend on the pinned CEF runtime and FFmpeg/libyuv/private runtime dependencies described by the build manifests; the archive does not bundle a full CEF SDK. Paths/RPATHs reflect the measured host. Rebuild from source-final using the saved pins/build options for a different host. Fuzz binaries use Clang ASan/UBSan and are not release benchmarks.
