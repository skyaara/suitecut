# SuiteCut

SuiteCut is a Node.js library for recording and streaming narrated browser flows.
Create product demos and tutorials with local narration, captions, highlights,
zoom, and checkpoints, then render videos from saved recordings and manifests.

SuiteCut 2.0 uses embedded Chromium (CEF) by default and also supports Playwright.
